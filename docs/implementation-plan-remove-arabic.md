# الخطة المنقحة: إزالة العربية فقط مع الحفاظ على الموقع

التاريخ: 11 نوفمبر 2026.

هذه النسخة تحل محل توصيات التنفيذ في `implementation_plan.md` المرفقة بالطلب. الملف الأصلي مرجع تاريخي؛ النسخة المنقحة داخل المشروع لتكون قابلة للمراجعة والحفظ في Git.

## القرار المعتمد

الموقع يبقى بالإيطالية والإنجليزية، والإيطالية هي اللغة الافتراضية. المطلوب إزالة العربية فقط، مع الحفاظ على الشكل والمحتوى والصور والأنيميشن والأسعار وتجربة الاستخدام الحالية للغتين الباقيتين.

أُنشئ أولًا checkpoint للحالة الحالية في `437936b0b6939b35b8faa7d8a2f029134093dd61`، ورُفع إلى `main` بطلب صريح من صاحب المشروع. تنفيذ إزالة العربية يأتي بعده على الفرع المحلي `codex/remove-arabic-keep-it-en`؛ لا يُرفع ولا يُنشر تلقائيًا ضمن هذه المهمة.

## تصحيح الخطة الأصلية

| الاقتراح السابق | القرار المنقح وسببه |
|---|---|
| موقع إيطالي فقط وحذف الإنجليزية | مرفوض؛ الإنجليزية باقية بطلب صريح. |
| إزالة بادئات اللغات أو تغيير slugs | تُحفظ `/it` و`/en` وكل أسماء الصفحات. |
| حذف مبدّل اللغة | يُحفظ بنفس التصميم، ويُزال خيار العربية فقط. |
| حذف 29 ملفًا وصور وفيديوهات قبل العمل | خارج النطاق؛ تحليل reachability القديم لا يثبت أن الملفات الحالية قابلة للحذف بأمان. |
| إعادة كتابة المحتوى وH1 وتغيير الحجز والتذييل والأداء | أعمال مستقبلية منفصلة؛ قد تغيّر الموقع الذي يريد صاحبه الحفاظ عليه. |
| إزالة جميع `hreflang` | غير صحيح لموقع بلغتين؛ تبقى الإيطالية والإنجليزية و`x-default` حيث كان موجودًا، وتُزال العربية فقط. |
| منع أي ظهور لـ `ar` في المشروع كله | الفحص يستهدف كود التطبيق وقواميسه؛ قواعد تحويل الروابط القديمة والتوثيق تحتاج ذكر العربية. |
| تقسيم كل ملف بعد تجاوز 600 سطر | الحجم إشارة للمراجعة؛ لا إعادة هيكلة شاملة بلا حاجة، ولا مسؤوليات جديدة لهذه المهمة. |
| نسب ترتيب محلي ثابتة وأرقام تدقيق قديمة | لا تُعتمد بلا دليل حديث. لا حاجة لبحث SEO خارجي لتنفيذ إزالة لغة. |

معلومات المنافسين والقانون والملكية وحقوق الصور وتوفر الدومينات في الخطة الأصلية لم تُتحقق في هذه المهمة، ولا تُستخدم لتغيير المحتوى أو إعدادات الإنتاج.

## الثوابت التي يجب إثباتها

- قواميس `messages/it.json` و`messages/en.json` تبقى كما كانت عند الـ checkpoint.
- نصوص الإيطالية والإنجليزية في البيانات، والأسعار والصور والفيديوهات لا تتغير.
- البنية `[locale]` و`next-intl` ومبدلات اللغة الحالية تبقى.
- مسارات `/it/...` و`/en/...` ووجهاتها السابقة تُحفظ؛ تحويلات المنيو الموجودة تبقى.
- يبدأ `/` بالإيطالية حتى لو كان المتصفح أو ملف تعريف الارتباط القديم يفضل العربية.
- روابط `/ar` و`/ar/:path*` تعطي 308 إلى الصفحة المناظرة في `/it` مع حفظ query parameters. الجزء `#fragment` لا يصل إلى الخادم؛ لا نكتب قاعدة تحذفه.
- لا قاعدة بيانات ولا migrations مطلوبة. لا تعديل لإعدادات Vercel أو الدومين أو النشر في خطوة إزالة العربية.

## خطوات التنفيذ

### 1. تثبيت خط الأساس

1. قراءة `forward-architecture` وتعليمات المشروع ووثائق Next.js المثبتة الخاصة باللغات والتحويلات.
2. حفظ التعديلات القائمة ونسخة محلية من ملفات المصدر وحالة Git قبل التغيير.
3. مراجعة وفحص الحالة الحالية وإنشاء checkpoint ورفعه إلى `main` بناءً على طلب المستخدم اللاحق.
4. تسجيل عرض الصفحات بالإيطالية والإنجليزية على عرضي 1440 و390 بكسل للمقارنة.

### 2. إزالة اللغة من مصدرها

1. تعديل `routing.locales` إلى `['it', 'en']`، مع بقاء `defaultLocale: 'it'` و`localePrefix: 'always'` و`localeDetection: false`.
2. اشتقاق `LocaleCode` و`LocalizedText` من نوع اللغة المعتمد لتجنب قائمتين مستقلتين للغات.
3. حذف `messages/ar.json` ومدخل العربية من مبدّل اللغات، والإبقاء على زر المبدّل وأماكن عرضه.
4. حذف خصائص البيانات العربية وفروع النصوص العربية بتحويل يعتمد على TypeScript AST ويحافظ على النص المحيط.
5. إزالة فروع اتجاه العربية وخصائص `isRtl` غير اللازمة مع الحفاظ على قيم واتجاهات الإيطالية والإنجليزية الحالية. لا تغيير لملفات CSS أو حركات الموقع.
6. تحديث البحث الذي كان يفحص حقول `.ar` وسكربت فحص المنيو للغتين الباقيتين.
7. إزالة الكلمة العربية من عنوان مبدّل اللغة في Quick Hub فقط؛ لا إعادة كتابة لبقية المحتوى.

### 3. التوافق مع الروابط القديمة

إضافة قاعدة محددة واحدة إلى `next.config.ts`:

```ts
{ source: '/ar/:path*', destination: '/it/:path*', permanent: true }
```

تنفذ قبل معالجة `next-intl` حتى لا يعامل `/ar/menu` كمسار داخلي تحت `/it/ar/menu`. لا توجد قواعد تحويل جديدة لمسارات الإنجليزية أو الإيطالية. الصفحة غير الموجودة أصلًا تظل غير موجودة بعد التحويل، بدل إرسال كل الروابط إلى الصفحة الرئيسية.

### 4. الفحص ومنع الرجوع

- `pnpm run lint`: يبدأ بفحص اللغات ثم ESLint بحد صفر تحذيرات.
- `pnpm run typecheck` و`pnpm run build`.
- `pnpm check:locales`: يثبت اللغات المعتمدة، وتكافؤ مفاتيح القاموسين، وغياب المحتوى العربي ومراجعه القديمة من `src` و`messages`.
- `pnpm verify:locales <local-origin>` بعد تشغيل النسخة المحلية: يفحص مسارات manifest للغتين، وتحويلات العربية، وحفظ query parameters، وروابط اللغات و`lang` و`dir`، وملفات تعريف الارتباط والترويسات القديمة.
- مقارنة النصوص والروابط وتخطيط صفحات اللغتين بخط الأساس في المتصفح، مع تثبيت الفيديو والحركة في الصور حتى تكون المقارنة مفيدة.
- تجربة تبديل اللغة من شريط التنقل ومن Quick Hub، وقائمة الموبايل، والبحث ونافذة الحلويات والأسهم ولوحة المفاتيح.
- مراجعة diff للتأكد من عدم تغيير الصور والـ CSS والقواميس الباقية وعدم دخول أي ملفات مؤقتة إلى commit.

### 5. الإغلاق والرجوع الآمن

بعد نجاح الفحص، يُنشأ commit محلي مستقل للتنفيذ على فرع العمل. لا يُرفع هذا الفرع ولا يُدمج في `main` من دون تفويض جديد. الرجوع لاحقًا يتم بعكس commit إزالة العربية على فرع عمل؛ checkpoint السابق محفوظ على GitHub.

## سجل الفحص

- checkpoint الأصلي: `lint` و`typecheck` و`build` نجحت؛ 48 حالة عرض في المتصفح نجحت دون أخطاء JavaScript.
- تحقق GitHub من أن `main` يشير إلى الـ checkpoint. حالة نشر الـ checkpoint على Vercel هي `READY`؛ إعدادات الحماية لم تتغير ضمن هذه المهمة.
- تحقق التنفيذ: `lint` و`typecheck` و`build` نجحت. تأكدت مطابقة القاموسين و2012 قيمة إيطالية وإنجليزية، وبقاء 229 طبقًا و43 مشروبًا بلا تكرار. أُصلحت توقعات فحص المنيو القديمة اعتمادًا على بيانات الـ checkpoint.
- نجح فحص HTTP لـ 26 مسارًا بالإيطالية والإنجليزية و13 تحويلًا من العربية، مع حفظ المعاملات وبقاء الإيطالية افتراضيًا. نجح تبديل اللغة من الشريط وQuick Hub، وفتح قائمة الموبايل وإغلاقها، والبحث والتنقل في صور الحلويات.
- ظهر تنبيه من Next.js عن مشكلة أمان في الإصدار المثبت قبل إزالة العربية. الترقية عمل منفصل حتى لا يتوسع نطاق التغيير.
- مقارنة المتصفح: 48 حالة بالإيطالية والإنجليزية دون أخطاء JavaScript، مع تطابق النصوص والروابط في المحتوى والتذييل. أُعيد فحص 20 حالة بعد استقرار الحركة مقابل الـ checkpoint المنشور: تطابقت مواضع العناصر وأبعادها والخطوط. لم تُعتمد مطابقة كل بكسل بين النشر والتشغيل المحلي لأن توقيت تحميل الصور اختلف في بعض اللقطات. لم تتغير ملفات الصور أو CSS.
